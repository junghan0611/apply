* Summary

I build agent platforms, not agent demos. On the harness side: a dispatch substrate that lets
different agent harnesses address one another by id without owning each other's transcript, auth,
or runtime, published on npm and extended by an outside contributor for an enterprise runtime I
had never written for. On the memory side: semantic retrieval as an independent layer — LanceDB
with hybrid vector + FTS search, score normalization, cross-lingual expansion through a personal
vocabulary graph. On the operations side: five months and 20+ upstream version cycles of running
a multi-agent harness in production, including a latency regression I instrumented, rolled back
on evidence, and turned into an upgrade policy.

What I care about is the part most agent projects skip: what the agent is allowed to touch, what
evidence it must leave, where it must stop, and how a human picks the work back up. I have built
that for a personal knowledge corpus of thousands of notes and for domain owners at work who
asked not for a dashboard but for "make this run without me." The same background covers the
layers underneath — embedded firmware, protocols, backend services — so the agent layer is not
being designed by someone who has never had to make the system beneath it work.
