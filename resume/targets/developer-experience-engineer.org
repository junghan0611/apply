* Summary

I build the surfaces other people and agents work on: 40+ skills over a real corpus, one skill SSOT
fanned into five harnesses, a fenced Emacs agent server, a Forgejo work ledger, and document tools
that carry Korean HWPX, scanned paper, EPUB, Org, and office formats across otherwise disconnected
systems. The goal is not another wrapper. It is an installable path with ownership, boundaries,
provenance, diagnostics, and a hand-off the next person can recover.

Documentation is part of the executable surface. Release notes become repository-specific impact
notes; operating charters state what an agent owns and does not own; generated artifacts lead back
to one source and one build command. When a built CLI is installed, its source revision, source-tree
digest, and binary SHA-256 are recorded. If reality drifts from the document, the check should say so
before a user has to infer it from a failure.
