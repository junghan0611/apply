* Summary

I build the surfaces other people work on. 40+ agent skills over a real corpus rather than a demo
context; a dispatch substrate that lets different agent harnesses address one another without
owning each other's transcript, auth, or runtime; a self-hosted code work surface where an agent
turns a conversation into a durable, reviewable work item; a fenced Emacs agent-server exposing 10
path-guarded APIs, so agents are given a playground rather than a list of prohibitions. If an
agent breaks something inside that fence, I treat it as a design problem, not an agent problem.

Documentation is not a chore appended to the work — it is the work. I translate upstream releases
into per-repository impact notes so a team knows where to look, and I keep operating charters that
let agents from different vendors work under one house's grammar. The corpus behind that is public
and countable: 2,200+ published pages, 3,500+ notes, 1,600+ consecutive days of journaling, all
cross-referenced on one identifier scheme. Even this résumé is generated from a single Org source
through a reproducible pipeline — the same claim, demonstrated rather than asserted.
