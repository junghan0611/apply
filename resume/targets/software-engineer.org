* Summary

I work from the firmware up to the agent loop. On one end: a Zigbee hub written in Zig, now
shipping in mass production, with the server (Go) and the companion app (Flutter) I built on top
of it because the original contract stopped at firmware. On the other end: a dispatch substrate
for AI agent harnesses, published on npm and extended by a contributor I have never met. The
middle is not empty — it is a reproducible NixOS/Emacs environment where the tools, the memory,
and the boundaries are designed rather than improvised.

This is not "full stack" in the front-end/back-end sense. It is depth across a vertical: silicon,
protocol, service, interface, agent. I tend to build before claiming expertise — build something
small, find where it breaks, preserve the evidence, and turn that failure into reproducible tools
and ways of working. Hands-on across Go, Clojure, Zig, C, TypeScript, Nix, and Elisp, with a
public corpus of code and notes that can be read rather than taken on trust.
