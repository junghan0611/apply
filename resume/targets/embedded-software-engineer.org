* Summary

My foundation is systems software: NVM block device drivers, persistent-memory data structures,
NUMA behaviour, and in-kernel device virtualization. Earlier research includes coauthored work on
MyAV, a mobile virtual machine monitor, and para-virtualized / exitless I/O. I now connect that
kernel and virtualization background to public SDK-based BSP builds: SG2000 boot-chain
configuration and a captured RISC-V Linux / Buildroot boot on a Milk-V Duo S.

I have also taken Linux-based embedded products through hardware integration and mass production.
Recent work includes Zigbee gateway firmware in Zig/C with a type-safe vendor-SDK boundary,
deterministic state transitions and aging-test automation; board HAL extraction across an
ARMv7/glibc to RISC-V/static-musl port; and Yocto / Android platform integration. Personal Go/Flutter
prototypes extend firmware verification, not company server/app delivery. My focus is reliable
board-to-product integration, repeatable test tools, and clear hand-offs across hardware and
software teams.
