* Summary

I take embedded products from silicon to shipping. Most recently a Zigbee/Wi-Fi gateway written in
Zig, now in mass production: a legacy C Zigbee SDK integration rewritten behind a type-safe FFI
layer, a deterministic state machine (single =HubState=, pure =transition()=), and 24-hour aging-test
automation. When the contract stopped at firmware I built the server (Go) and the companion app
(Flutter) myself and turned a deliverable into a product — one protocol served by two
interchangeable backends, AWS IoT and a local mTLS broker, with the firmware shipping unmodified
in both.

The next-generation hub is where the engineering judgment shows: port target moved from ARMv7
glibc with a vendor sysroot to RISC-V on statically linked musl; a board HAL extracted so the hub
core no longer knows what board it runs on; Zigbee transport delegated to Zigbee2MQTT; seven
hardcoded device-type handlers dropped so the device model passes through as a generic entity.
Alongside it, a Matter hub with an on-device AI agent runs from one Go codebase on RPi5 + Hailo-8
NPU (Yocto) and RK3576 (Android) with 96% code sharing. I started in systems software research
(non-volatile memory filesystems, NUMA locks) and co-founded a company that shipped a Linux-based
touch display OS, so the habit of owning the whole stack is not new.
