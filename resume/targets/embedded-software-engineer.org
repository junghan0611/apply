* Summary

I take embedded products from silicon to shipping. Most recently: a Zigbee/Wi-Fi gateway written in
Zig and shipped to mass production, with a legacy C SDK isolated behind type-safe FFI, one explicit
state machine, and aging-test automation. When the contract stopped at firmware, I built the Go
server and Flutter companion app and delivered one protocol over two interchangeable backends — AWS
IoT for connected deployments and a local mTLS broker for closed networks — without changing the
firmware.

The next port moved from ARMv7/glibc and a vendor sysroot to RISC-V on static musl, extracted a board
HAL, delegated Zigbee transport to Zigbee2MQTT, and removed hardcoded device handlers. In
parallel, one Go Matter-hub codebase runs on both RPi5 + Hailo-8 NPU/Yocto and RK3576/Android.
Underneath the product work is a reproducible open-source boot chain — bootloader through kernel to
FreeRTOS on a dual-ISA SoC — that traces back to graduate research on the memory hierarchy: NVM
block device drivers, write-amplification reduction, and NUMA-aware persistent-memory data
structures. AI appears here as an engineering tool and deployable edge workload, not as a claim of
model-training expertise.

* Public Evidence — Build Surface and Honest Boundary

- *Boot chain* — [[https://github.com/junghan0611/homeagent-config/tree/main/bsp][github.com/junghan0611/homeagent-config/bsp]] builds a dual-ISA SoC's full boot
  chain (fsbl → OpenSBI → U-Boot → kernel → rootfs → FreeRTOS) from public sources and a pinned
  public SDK; the build injects the committed board and Buildroot defconfigs (=./bsp/build.sh=,
  =./bsp/flash-emmc.sh=). [[https://github.com/junghan0611/homeagent-config/blob/main/docs/TARGET_DEVICE.md][docs/TARGET_DEVICE.md]] documents the board memory map as a single
  generated source feeding the bootloader, kernel, and FreeRTOS linker; [[https://github.com/junghan0611/homeagent-config/blob/main/docs/DUO-S-BUTTONS.md][docs/DUO-S-BUTTONS.md]]
  establishes by DTS inspection, not assumption, that the board carries no gpio-keys node.
- *Product implementation* — [[https://github.com/junghan0611/homeagent-config][github.com/junghan0611/homeagent-config]]'s Go/Flutter/Matter/Yocto
  system and build entries: =./run.sh go-build=, =flutter-server=, =bundle=.
- *Boundary* — the mass-production SKS firmware and customer data are private. HomeAgent is a public,
  adjacent implementation that verifies the boot-chain and Matter/Go/Flutter/Yocto work; it is not
  offered as proof of the private shipment claim. That claim remains attributable employment
  experience.
