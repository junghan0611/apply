# 영문 이력서가 공유하는 LaTeX 조판 선언. 베이스 정본과 타깃 컷이 모두 #+INCLUDE 로 끌어온다.
#
# 여기 있는 것은 전부 #+latex_header 키워드다. 문서 본문(body.org)은 자기가 어느 컷으로
# 나갈지 몰라도 된다. 사실 모듈은 한 벌이고, 타깃 정본이 서사·증거 입구·모듈 선택 순서를
# 쥔다. 조판은 어느 컷인지 알 필요가 없다.
#
# dossier/ 의 제출 파이프라인과 같은 flake devshell 을 쓰지만 조판 클래스는 다르다. 저쪽은
# acmart(논문 조판)이고 이력서는 article 이다. 이력서를 논문 판형에 얹으면 두 쪽이면 될
# 문서가 네 쪽이 된다.

#+latex_class: cvpaper
#+latex_class_options: [10pt,a4paper]
#+latex_compiler: xelatex

# ── 활자 ──────────────────────────────────────────────────────────────────────
# flake 가 Pretendard·D2Coding 을 빌드 입력으로 고정한다. 받는 쪽에 활자가 없으면 XeTeX 는
# 조용히 대체 활자로 짜고 페이지는 멀쩡히 나온다 — 실패가 눈에 보이지 않는 종류라서,
# 활자를 환경에 맡기면 "같은 소스에서 같은 문서가 나온다" 는 말을 지킬 수 없다.
#
# 영문 이력서지만 한글이 섞인다(김정한·힣). xetexko 가 스크립트로 갈라 한글만 한글 조판
# 규칙으로 처리하고, 라틴 본문은 fontspec 이 그대로 맡는다.
#+latex_header: \usepackage{fontspec}
#+latex_header: \usepackage{xetexko}
#+latex_header: \setmainfont{Pretendard}[Ligatures=TeX]
#+latex_header: \setsansfont{Pretendard}
#+latex_header: \setmonofont{D2Coding}[Scale=0.90]
#+latex_header: \setmainhangulfont{Pretendard}[Ligatures=TeX]
#+latex_header: \setsanshangulfont{Pretendard}
#+latex_header: \setmonohangulfont{D2Coding}
# 한자는 Pretendard 에 글리프가 없다. 없으면 로그에만 "Missing character" 로 남고 PDF 에는
# 빈칸으로 찍힌다 — run.sh 가 그 로그를 세어 실패로 막지만, 애초에 구멍을 막아 둔다.
#+latex_header: \setmainhanjafont{D2Coding}

# ── 판면 ──────────────────────────────────────────────────────────────────────
# 이력서는 읽는 사람이 훑는 문서다. 논문 판면(3cm)으로 짜면 한 줄에 들어갈 항목이 접혀서
# 불릿 하나가 두 줄이 되고, 두 쪽이면 될 문서가 네 쪽이 된다.
#
# 판면을 여기서 한 번 조인 이유: 이 이력서는 3쪽에 들어가야 하는 분량인데 1.7cm 여백과
# 1.04 행간으로는 마지막 절 하나가 넷째 쪽으로 넘어가고, 그 쪽의 3분의 2가 빈다. 읽는
# 사람에게는 "네 쪽짜리 이력서" 로 보이고 실제로는 세 쪽 반이다. 내용을 깎아 맞추는 대신
# 판면에서 먼저 찾는다 — 여백 0.2cm 와 행간 4%면 한 쪽에 가까운 차이가 난다.
#+latex_header: \usepackage[a4paper,left=1.5cm,right=1.5cm,top=1.3cm,bottom=1.25cm,footskip=0.7cm]{geometry}
#+latex_header: \usepackage{microtype}
#+latex_header: \setlength{\parindent}{0pt}
#+latex_header: \setlength{\parskip}{2.5pt plus 1pt minus 0.5pt}
#+latex_header: \linespread{1.0}
# 판면을 몇 pt 넘긴 줄 하나 때문에 문장을 고쳐 쓰는 일이 없게, 마지막 줄에 약간의 신축을
# 허용한다. \sloppy 처럼 문서 전체의 어절 간격을 풀지 않고 넘칠 때만 늘린다.
#+latex_header: \setlength{\emergencystretch}{1.2em}

# ── 색 ────────────────────────────────────────────────────────────────────────
# 두 가지만 쓴다. accent 는 표제와 링크, muted 는 기간·부가 정보. 이력서에서 색이 셋을
# 넘어가면 강조가 강조를 지운다.
#+latex_header: \usepackage[dvipsnames]{xcolor}

#+latex_header: \usepackage{url}

# ── 표제 위계 ─────────────────────────────────────────────────────────────────
# 세 단(절 → 소절 → 소소절)을 크기·색·괘선으로 가른다. 절 아래 괘선은 눈이 문서를 훑을 때
# 잡는 첫 번째 격자다. 소절은 "회사 — 역할 \hfill 기간" 한 줄을 쥐므로 hang 정렬이어야
# \hfill 이 살아난다(block 정렬은 제목을 박스에 넣어 hfill 을 죽인다).
#+latex_header: \usepackage{titlesec}

#+latex_header: \titlespacing*{\section}{0pt}{8pt plus 2pt minus 1pt}{4pt}

#+latex_header: \titlespacing*{\subsection}{0pt}{6pt plus 1pt minus 1pt}{2pt}
#+latex_header: \titleformat{\subsubsection}[hang]{\sffamily\bfseries\small\color{muted}}{}{0pt}{}
#+latex_header: \titlespacing*{\subsubsection}{0pt}{4.5pt plus 1pt minus 1pt}{1pt}

# ── 목록 ──────────────────────────────────────────────────────────────────────

# 한 쪽에 들어갈 경력이 두 쪽으로 흩어진다.

# "마지막 열이 없는 표" 로만 보여서, 지운 적 없는 내용이 사라진다. 조판 계층에서 막는다.

# ── 표제 블록 ─────────────────────────────────────────────────────────────────
# 타깃 컷이 바꾸는 것은 이 한 줄(부제)뿐이다. 이름·연락처·이름 병기는 모든 컷에서 같으므로
# 매크로가 쥐고, 각 정본은 \cvheader{...} 를 한 번 부른다.
#
# 이름 병기가 부제 옆에 앉는 이유: 이 사람의 공개 작업물 절반이 한글 이름과 별명으로
# 검색된다. 이력서를 읽은 사람이 GitHub·가든에서 같은 사람을 찾을 수 있어야 증거가 이어진다.
