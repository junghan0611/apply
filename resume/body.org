  legacy C Zigbee SDK integration behind Zig's type-safe FFI layer; deterministic state machine
  (single =HubState=, pure =transition()=) across driver, protocol, and cloud layers; aging-test

  board it runs on; delegated Zigbee transport to Zigbee2MQTT (EFR32MG24); went device-agnostic by
  dropping hardcoded device-type handlers.
