## 직무 소개 (요약)

자체 설계한 SoC의 부트로더를 개발하고 Embedded Linux를 포팅하는 자리. SoC 하드웨어를
초기화·제어하는 드라이버를 직접 구현하고, CXL 인터페이스 제어와 NVMe SSD 기반 메모리 확장을
제품에 적용한다. 「부팅 초기 단계부터 커널과 드라이버까지 임베디드 소프트웨어 스택 전반」.

## 주요 업무 (원문 5줄)

1. EPROM 및 SPI Flash 기반 부트로더를 개발합니다
2. ARM Cortex 코어에 Embedded Linux를 포팅합니다
3. DRAM, SPI, I2C, UART 등 장치를 초기화하고 제어하는 드라이버를 구현합니다
4. CXL 인터페이스 드라이버를 개발합니다
5. NVMe SSD를 활용한 메모리 확장을 구현합니다

### 경계 — 숨기지 않는다

주요 업무 5줄 중 **④ CXL 드라이버 · ⑤ NVMe 메모리 확장은 수행 경험이 없다.** 우대의
**Secure Boot 도 없다.** 인접한 것은 있다 — 대학원 축이 **NVM 블록 디바이스 드라이버 ·
NVM 쓰기 증폭 감소 · 비휘발성 메모리 인덱스 · NUMA PM 자료구조 노드 리플리케이션**이고,
이것이 CXL 이 푸는 tiered memory 문제의 바로 옆자리다. **NVM ≠ NVMe** 이므로 두 단어를
섞어 쓰지 않는다(자기소개서 §4 가 이 구분을 명시로 적는다).
