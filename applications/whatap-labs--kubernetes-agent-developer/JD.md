「Kubernetes 클러스터 내 Node, Pod, Container 등 핵심 오브젝트의 메트릭 수집 파이프라인을
개발합니다. 와탭랩스는 IT 서비스를 운영하는 엔지니어들을 위한 플랫폼을 만드는 글로벌 AI
기업입니다. 인프라스트럭처∙애플리케이션∙데이터베이스에 대한 통합 성능 분석에서 GPU∙LLM과
같은 AI 대상의 성능 분석 서비스까지 제공합니다.」
와탭랩스 쿠버네티스 에이전트 개발 포지션의 처우는 7,000만원 이상으로 책정.

### 주요업무

- Kubernetes 클러스터 내 Node, Pod, Container 등 핵심 오브젝트의 메트릭 수집 파이프라인을 개발합니다.
- 대규모 트래픽 환경에서 안정적인 메모리 최적화 및 비동기 데이터 처리 구조를 설계하고 고성능 에이전트를 구현합니다.
- On-premise, Public Cloud 등 다양한 Kubernetes 환경에서의 호환성을 확보합니다.
- NVIDIA GPU, MIG(Multi-Instance GPU) 등 AI 인프라 자원에 대한 모니터링 서비스를 개발합니다.
- GPU 하드웨어 메트릭과 Kubernetes Pod, 애플리케이션 정보를 매핑하여 병목 구간을 추적하는 통합 분석 기능을 구현합니다.
- 수집된 데이터를 바탕으로 고객에게 필요한 대시보드와 기능을 직접 기획하고 프로토타입을 개발합니다.
- 기술적 연구 성과를 제품화하여 엔터프라이즈 고객이 만족할 수 있는 수준의 완성도를 확보합니다.

### 자격 요건

- 네트워크, OS(Linux), 파일시스템, 자료구조에 대한 이해
- 멀티 스레드 프로그래밍 및 소켓 통신에 대한 이해
- 대용량 데이터 처리 시 메모리 효율과 최적화를 고민하며 개발한 경험
- 다양한 고객 환경에서의 이슈 분석 및 해결책 제시 경험
- Java 또는 Go 언어 중 하나 이상 능통
- Kubernetes 아키텍처 및 리소스 모델에 대한 이해
- 공식 문서 및 기술 문서를 기반으로 동작 원리를 파악하고 모니터링 기능을 구현할 수 있는 능력
