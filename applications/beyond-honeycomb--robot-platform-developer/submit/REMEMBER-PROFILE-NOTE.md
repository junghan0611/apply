앱에 등록해 둔 프로필이 그대로 전형에 쓰였다.

**GLG 진술 (2026-09-04, `superbin--robot-sw-engineer/submission.md` 최초 기록)**: *「정보가 없으면
다 그냥 내가 앱에서 올린 거야. 앱에서 제출한 것들은 다 같은 이력정보를 넣어서 하거든.」*

- 제안 수락일: **미확인** (결과 메일에만 남아 있고 수락 시점 알림은 채집되지 않았다).
- 경로: 리멤버(Remember) 앱 — 회사발 스카웃 제안 → GLG 수락.
- 첨부 파일: **없음.** 별도 업로드 없는 플랫폼 프로필 기반.

  결과·결과 통보일뿐이다. 기억으로 복원하지 않는다.
