## ⛔ 지원분야를 왜 이 자리로 골랐나 — 그리고 무엇을 내려놓았나

**카카오뱅크 열린 공고 25건 중 개발 축은 8건이고, `AI` 직군은 0건이다**(`JD.md` §같은 회사
다른 열린 공고). 판정 전문은 그 표에 있고, 요지는 둘이다.

| 자리 | 왜 이것 / 왜 아닌가 |
|---|---|
| ⭐ **데이터 엔지니어 - Data Warehouse** | **골랐다.** 필수 5개 중 4개가 붙고(경력 3년+ · SQL/Python · ETL/ELT · DB 설계 부분), 우대에 **「에이전틱 코딩(Agentic Coding) 경험」** 이 박혀 있다. 이 배치에서 그 단어를 공고에 쓴 회사는 드물다 |
| **서버 개발자 - 뱅킹** (`260505`, D-11) | **JD 서사는 이 회사에서 가장 정면이다** — *"Claude Code와 GitHub Copilot Enterprise 등 AI 도구를 팀 전체가 실무에 활용"*, 담당업무에 **AI 도구를 개발 프로세스에 통합하는 실험**, 필수 항목에 **문서·공유 세션·코드리뷰로 지식을 남기는 사람**. 🔴 그런데 필수가 **Kotlin 또는 Java + Spring Boot + ORM 실무 1년+** 이고 **이력서 언어에 JVM 이 0건**이다(Go · Clojure · Zig · C · TypeScript · Elisp · Nix · Bash · Python). **지어내지 않는다**(`AGENTS.md` §경계). 낼지는 **GLG 판단** — 한화 건처럼 「인력풀에 이름을 남기는」 목적이면 던질 수 있다 |
| 데이터 엔지니어 - Data Mart | 필수에 **BI 시스템·경영지표·대내외 보고 데이터셋/리포트 개발·운영**이 추가로 붙어 DW 보다 멀다 |
| 블록체인 백엔드 · 시장리스크(계약직) · 수신업무 도메인 | `JD.md` 표에 이유를 남겼다 |

🔴 **이 자리의 하드 갭은 하나이고 그것이 필수 항목이다 — 「데이터 웨어하우스(DW) 구축 및 운영
경험」.** 전사 DW 를 세우거나 운영한 적이 없다. 자기소개서에서 **이 갭을 숨기지 않는다.**
대는 것은 ETL/ELT 실적(Airbyte 커넥터 → PostgreSQL JSONB · n8n)과 운영 데이터를 하나의
시간축·증거 체계로 묶은 `incidentcli`·`voscli` 이고, 그것이 DW 구축과 같은 것이 아니라는 사실을
글에서 먼저 말한다.
