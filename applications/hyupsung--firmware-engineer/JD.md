# 협성기전 — 2026년 연구소 Firmware 개발 엔지니어 채용 (경력)

- 확인: 잡코리아 접수 완료 메일 본문, 2026-10-25 04:19 KST 수신·당일 조회.
- 확인된 것은 회사·공고명·접수 사실이다. 공고 URL·담당업무·필수요건은 미회수이며 제목에서 추정하지 않는다.
- 이미 제출한 건의 사후 기록이다. 요건 매트릭스·적합도 판정은 하지 않았다.
- 서류 합격 후 필요한 최소 입력: 해당 공고의 공개 URL 또는 담당업무·필수요건 텍스트. 원문 미확인은 JD 기반 면접 준비를 막지만 제출 완료 사실을 바꾸지 않는다.
