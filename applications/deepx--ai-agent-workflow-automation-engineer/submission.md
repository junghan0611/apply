**둘째, 온프레미스를 전제로 한다.** 임베딩·리랭킹을 외부 API로 넘기지 않고 사내 GPU에서 직접

**셋째, 반도체 회사가 사내 개발 생산성에 사람을 따로 뽑는다.** 칩을 만드는 조직이 코드
에이전트 인프라 전담을 여는 것은 개발 규모가 이미 그 문제를 만들었다는 뜻이다. 자동화가
장난감이 아니라 병목인 자리다.
