- (제품화) 펌웨어 위에 서버(Go)와 컴패니언 앱(Flutter)을 직접 구축하여 펌웨어 납품물을 완결된 제품으로 확장. 하나의 프로토콜을 AWS IoT(연결형)와 로컬 백엔드(폐쇄망) 두 백엔드로 서비스(펌웨어는 무수정 동작). mTLS 로컬 브로커, 섀도 미러링, 멀티 허브 팬아웃을 실제 하드웨어에서 검증.
- (차세대 허브) 포팅 타깃을 ARMv7/glibc에서 RISC-V(SG2000)·static musl로 이전, 보드 HAL을 추출하여 허브 코어를 하드웨어 독립적으로 재설계, Zigbee 전송을 Zigbee2MQTT(EFR32MG24)로 위임, 디바이스 애그노스틱 전환.

- 3-에이전트 병렬 개발 세션 관리(하루 24커밋, 163 테스트 통과, 파일 충돌 0). Linux·Android 간 96% 코드 공유.

- 국가 R&D(IITP, 2025~2028) 지능형 홈 과제: sLLM 음성제어, Matter 통합, NPU 워크로드 포팅 수행(현재 2년차).
