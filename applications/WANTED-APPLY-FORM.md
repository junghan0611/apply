# 원티드 지원 폼 — 15건이 공유하는 한 벌 (2026-09-18 실측)

원티드 경로로 열려 있는 케이스 15건은 **같은 지원 폼**을 쓴다. 건마다 다른 것은 공고 상태·경력
요건·국적/비자 필수 여부뿐이고, **폼의 구조는 하나다.** 그러니 구조는 여기 한 벌로 두고 각
`submission.md` 는 이 문서를 가리킨다 (`AGENTS.md` §SSOT — 사실은 한 벌이고 뷰는 선택·배열만 한다).

⚠ **이 문서는 「원티드 자체 지원」에만 해당한다.** 회사 자체 ATS 로 튕기는 공고는 폼이 전혀
다르다 — 그 판정법은 아래 §지원 경로에 있다.

## 지원 경로 — 원티드 자체 지원인가, 회사 ATS 로 튕기는가

**판정 필드는 `out_link` 다.** 로그인 없이 공개 API 로 읽힌다.

```bash
curl -s "https://www.wanted.co.kr/api/chaos/jobs/v1/<id>/details" | python3 -c \
  'import json,sys; j=json.load(sys.stdin)["job"]; print(j["status"], repr(j["out_link"]), j["company"]["name"])'
```

- `out_link: null` → **원티드 자체 지원.** 원티드 안에서 끝난다.
- `out_link: "<주소>"` → **회사 자체 ATS 로 나간다.** 원티드는 「기업 사이트에서 지원하셨나요?」
  팝업으로 지원 완료를 사후 표시만 한다.

🔴 **`null` 을 「측정 실패」로 읽지 않으려면 대조군이 필요하다.** 2026-09-18 에 테슬라 공고
(`wd/372650`)로 대조했더니 같은 필드에 외부 ATS 주소가 실려 있었다. 필드가 동작하는 것을 확인한
뒤에야 `null` 이 「외부 링크 없음」이라는 값이 된다.

**2026-09-18 실측 결과: 대상 15건 전부 `out_link: null` — 전부 원티드 자체 지원.**

## 첨부 — 「슬롯」이 아니라 이력서 탭 파일 목록의 체크박스

원티드 지원 화면에는 파일을 올리는 슬롯이 없다. **[이력서] 탭에 이미 올려둔 파일 목록이 뜨고
거기서 체크박스로 고른다.** 최소 1개가 체크돼야 제출 버튼이 활성화되고, 복수 선택이 된다.

| 사실 | 영수증 (원티드 고객센터, 공개 문서) |
|---|---|
| 체크박스 최소 1개가 필수이고, 미체크면 제출 버튼이 회색이다 | 「제출하기 버튼이 비활성화(회색)되어 있어요.」 — *「첨부파일에 이력서 체크 박스가 해제되어 생긴 현상 입니다. 제출할 이력서 옆 체크 박스(□) 버튼을 선택 하시면 버튼이 활성화(파란색) 됩니다.」* |
| 고른 파일만 기업에 간다. 이력서 탭의 나머지는 안 보인다 | 「지원한 기업에서 이력서탭의 모든 이력서와 파일을 확인할 수 있나요?」 — *「지원 당시 [지원하기]에서 선택 후 제출하신 첨부파일만 확인할 수 있습니다.」* |
| 내 파일을 쓰려면 먼저 이력서 탭에 업로드한다 (pdf·docx) | 「내가 만든 파일을 사용하고 싶어요.」 — *「① 메인화면 상단 [이력서] 탭 클릭 ② 최근 문서 내 파일 업로드」* |
| 포트폴리오는 기본 이력서 하단 「링크」 항목에 URL 로 넣는다 | 「기본 이력서에 포트폴리오를 첨부할 수 있나요?」 — *「기본 이력서 하단 '링크' 항목에 파일 URL 을 삽입해 주세요.」* |
| 추천사는 없어도 지원된다 | 「지원 시 추천사가 꼭 필요한가요?」 — *「입사 지원 시, 추천∙추천사 없이도 지원 가능 합니다.」* |

### 🔴 컷 PDF 선행조건 — 지금 막혀 있는 자리

**`resume/build/` 의 컷 PDF 는 지원 화면에 자동으로 뜨지 않는다.** 먼저 [이력서] 탭에 올려야
체크박스에 나타난다. 그리고 **2026-09-18 현재 올라가 있지 않다.**

이력서 탭 실측 (2026-09-18, `wanted.co.kr/cv/list`):

| | |
|---|---|
| 기본 이력서 | 1건 · 작성 완료 · **26.08.03** |
| 그 밖 | 작성 완료 1건(25.10.02) · 작성 중 2건(26.07.24 · 25.05.14) |
| **2026-09-18 재빌드 컷 PDF** | **0건** |

즉 지금 이 상태로 원티드에서 지원하면 **8월 3일자 기본 이력서**가 나간다. 9월 18일 재빌드분
(`platform-engineer` 신설 · FDE 컷 축 정정 · 자가 측정 수치 제거)은 반영되지 않는다.

⛔ **에이전트가 올리지 않는다.** 계정 자산을 바꾸는 행위이고 개인 계정 소관이다
(`AGENTS.md` §사람의 권한). **GLG 가 올린다.**

## 서술형 문항 — 기업 추가 문항 칸이 없다

원티드 자체 지원 경로에는 **기업이 붙이는 서술형 문항이 없다.** 지원 요청 페이로드에 자유서술
필드가 존재하지 않는다.

- 실측: 지원 페이지 번들(`6528-*.js`, 2026-09-18)이 `POST /api/chaos/applications/v1` 에 싣는 키는
  `username · email · mobile · nationality_code · user_visa_info · visa · position_id ·
  position_category_id · company_id · resume_key` 다. 자유서술·문항·답변 키가 없다.
- 고객센터 검색(「사전 질문」·「추가 질문 지원서」·「자기소개 입력」)에도 개인회원 지원 폼의
  서술형 문항을 설명하는 문서가 없다.

⚠ **경계.** 이건 **페이로드와 공개 문서로 세운 판정**이지 지원 모달을 열어 눈으로 센 것이 아니다.
아래 §남은 미실측을 함께 읽는다.

➡ 따라서 `FAQ.md` §9 의 서술형 단골 답(500~1,000자 자유 서술 · 문의 사항 · 300자 캡 3문항)은
**원티드 경로에서는 쓸 자리가 없다.** 그 답들은 회사 자체 ATS·그리팅·ninehire 경로에서 쓴다.

## 개인·법적 값 칸

| 칸 | 어디서 오는가 |
|---|---|
| 이름 · 이메일 · 연락처 | 원티드 프로필에서 자동으로 실린다 (페이로드 `username · email · mobile`) |
| 국적 · 비자 | **글로벌 포지션에서만 필수** (페이로드 `nationality_code · user_visa_info · visa`). 고객센터: *「글로벌 포지션의 경우에는 국적이 필수로 입력되어야 합니다.」* 건별 판정은 `visa_information` 필드로 한다 |

🔴 **값 자체는 이 저장소가 갖지 않는다.** 생년월일·병역·학력·직장경력 같은 신원·법적 값의 SSOT
는 private Org 면이다 (`AGENTS.md` §신원·법적 값의 SSOT). 케이스 파일에 사본을 만들지 않는다.
다만 원티드 경로는 프로필이 자동으로 실리므로 **이 경로에서 GLG 가 손으로 채울 칸은 사실상 없다** —
글로벌 포지션의 국적 한 칸을 빼면.

## 남은 미실측 — 한 번만 열면 15건이 함께 닫힌다

**지원 모달 내부를 직접 열어 보지 않았다.**

- 🔴 「지원하기」는 어느 화면에서도 클릭하지 않는다 (`.claude/skills/apply/SKILL.md` §4·§11).
- 원티드에는 **모달을 여는 다른 문이 없다.** 전용 라우트도 쿼리 파라미터도 없다 — 2026-09-18 에
  `__BUILD_MANIFEST` 를 읽어 `/wd/[jobId]` 와 `/wd/[jobId]/applied` 만 있고 `…/apply` 는 없음을
  확인했고, 페이지 번들에서 모달을 여는 쿼리 키(`query.*`)도 `jobId` 하나뿐이었다.
- 그래서 이 문서의 §첨부 · §서술형 문항은 **공개 고객센터 문서 + 지원 페이로드 키**로 세웠다.
  둘 다 열어 확인한 출처지만 모달 화면 자체는 아니다.

**GLG 가 아무 건에서 한 번 모달을 열어 확인해 주면 15건 전부가 같이 닫힌다.** 확인할 것 셋:

1. 체크박스 목록 말고 **별도 파일 업로드 버튼**이 모달 안에 있는가
2. **서술형 입력 칸**이 하나라도 있는가 (있으면 글자수 캡)
3. 프로필 자동 외에 **손으로 채울 칸**이 있는가
